## Overview

This repository is a complete academic VLSI design portfolio containing lab work across several stages of digital integrated circuit development:

- CMOS transistor-level gate design and characterization
- RTL modeling and functional simulation in Verilog
- Sequentials and state-driven logic design
- Arithmetic datapath construction and verification
- Standard-cell synthesis under timing constraints
- Pipelined datapath optimization
- Physical design concepts including placement, CTS, routing, and verification

## Technical Themes

### 1. CMOS and logic foundations

The early experiments focus on transistor-level CMOS logic and the physical behavior behind digital gates. Inverter and NAND/AND implementations illustrate how PMOS/NMOS devices form complementary logic structures, which are essential when translating logic equations into real silicon.

### 2. Verilog RTL design

The RTL sections of the repository demonstrate practical digital design using Verilog. Examples include:

- a 2:1 multiplexer using conditional assignment
- a half adder defined as `sum = a ^ b` and `carry = a & b`
- a 4-bit full adder using vector addition: `assign {carry, sum} = a + b + cin;`
- a 4-bit counter implemented with a clocked always block

These modules show how HDL reduces the implementation complexity of digital logic while keeping timing behavior explicit.

### 3. Sequential logic and synchronization

Sequential circuits are explored through D and JK flip-flops, along with a 4-bit up-counter. The design work highlights reset behavior, clock-driven state updates, and waveform analysis for verifying correct operation.

### 4. Synthesis and optimization

Experiments 06 and 07 shift from logic correctness to implementation quality. The designs are converted into gate-level netlists using standard-cell libraries and timing constraints, enabling analysis of:

- critical path delay
- timing slack
- power dissipation
- cell count and mapped structure

The pipelined adder demonstrates the trade-off between throughput and latency in datapath design.

### 5. Physical design flow

The final experiment introduces the physical design stage, where synthesized netlists are imported into a place-and-route flow. This includes:

- floorplanning
- power planning
- placement
- clock tree synthesis
- routing
- physical verification and netlist export
